# 18.82. Payment/Виды оплат 

| №  | Имя поля | Тип | Длина | Назначение |
| ---: | --- | --- | ---: | --- |
| 1  | ID  | Integer  |   | Уникальный идентификатор  |
| 2  | Code  | Integer  |   | Код  |
| 3  | Name  | Varchar  | 100  | Наименование  |
| 4  | Text  | Varchar  | 100  | Текст  |
| 5  | ECRPayment  | Integer  |   | Тип оплаты в ККМ  |
| 6  | Operation  | Integer  |   | Тип операции: • 0 – оплата наличными; • 1 – оплата банковской картой или QR-кодом; • 3 – оплата внутренней предоплатой; • 6 – оплата подарочной картой; • 7 – пользовательская; • 8 – оплата внешней подарочной картой.  |
| 7  | PayCardDevID  | Integer  |   | ID платежной системы  |
| 8  | Deleted  | Integer  |   | Признак удаления записи  |
| 9  | BDOCode  | Integer  |   | Код БД, в которой произведены изменения  |
| 10  | CHNG  | Numeric  | 18  | Счетчик изменений  |
| 11  | OwnerBDO  | Integer  |   | Код БД, которой передали записи при персональной синхронизации  |
| 12  | PrintGroupID  | Integer  |   | ID группы печати  |
| 13  | IsFiscalPayment  | Integer  |   | Флаг: фискальная оплата  |
| 14  | ReturnInCash  | Integer  |   | Флаг: разрешен возврат наличными  |
| 15  | ActivitiesCode  | Integer  |   | Код мероприятия  |
| 16  | FiscalOperation  | Integer  |   | Фискальный способ оплаты: • 0 – наличными • 1 – безналичными; • 2 – предоплатой (авансом); • 3 – постоплатой (кредитом); • 4 – иной формой (встречным предоставлением); • 5 – онлайн-касса не используется.  |
