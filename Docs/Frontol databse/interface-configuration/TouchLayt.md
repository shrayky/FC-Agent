# TouchLayt/Макеты сенсорного экрана

## Структура таблицы

| № | Имя поля | Тип | Длина | Назначение |
| ---: | --- | --- | ---: | --- |
| 1 | ID | Integer | | Уникальный идентификатор |
| 2 | Code | Integer | | Код |
| 3 | Name | Varchar | 100 | Наименование |
| 4 | Data | Blob | - | Данные макета |
| 5 | BDOCode | Integer | | Код БД, в которой произведены изменения |
| 6 | CHNG | Numeric | 18 | Счетчик изменений |
| 7 | OwnerBDO | Integer | | Код БД, которой передали записи при персональной синхронизации |

## Особенности

1. Поиск в БД производить по коду (Code).
2. При добавлении нового элемента нужно генерировать ID генератором GEN_ID (есть специальная функция в IFrontolMainDb - NextChangeId()).
3. BDOCode, CHNG, OwnerBDO - не нужно мапить, они внутренние поля фронртола.
