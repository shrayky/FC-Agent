# Comment/Комментарии

## Структура таблицы

| № | Имя поля | Тип | Длина | Назначение |
| ---: | --- | --- | ---: | --- |
| 1 | ID | Integer | | Уникальный идентификатор |
| 2 | Code | Integer | | Код |
| 3 | Text | Varchar | 100 | Наименование |
| 4 | Name | Varchar | 100 | Наименование |
| 5 | Deleted | Integer | | Признак удаления записи |
| 6 | BDOCode | Integer | | Код БД, в которой произведены изменения |
| 7 | CHNG | Numeric | 18 | Счетчик изменений |
| 8 | OwnerBDO | Integer | | Код БД, которой передали записи при персональной синхронизации |

## Особенности

1. Поиск в БД производить по коду
2. При добавлении нового элемента нужно генерировать ID генератором GEN_ID (есть специальная функция в IFrontolMainDb - NextChangeId())
3. Text и Name одинаковые
4. Deleted - не использовать (оно нужно для внутренней синхронихации фронтола).
