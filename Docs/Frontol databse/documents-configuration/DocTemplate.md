# DocTemplate/Шаблоны

## Структура таблицы

| № | Имя поля | Тип | Длина | Назначение |
| ---: | --- | --- | ---: | --- |
| 1 | ID | Integer | | Уникальный идентификатор |
| 2 | Code | Integer | | Код |
| 3 | Name | Varchar | 100 | Наименование |
| 4 | MinLines | Integer | | Минимальное число строк |
| 5 | MaxLines | Integer | | Максимальное число строк |
| 6 | BDOCode | Integer | | Код БД, в которой произведены изменения |
| 7 | CHNG | Numeric | 18 | Счетчик изменений |
| 8 | OwnerBDO | Integer | | Код БД, которой передали записи при персональной синхронизации |
| 9 | TemplateType | Varchar | 100 | Вид шаблона |
| 10 | FRData | BLOB | - | Шаблон в формате FastReport |
| 11 | MasterSettings | BLOB | - | Параметры мастера создания шаблона документа для ККМ |
| 12 | PrintTarget | Integer | | Назначение: 1 – ККМ чековая лента; 2 – ККМ подкладной документ; 3 – принтер чеков; 4 – принтер документов. |
| 13 | DocOrientation | Integer | | Флаг: повернуть на 180° |
| 14 | ScriptData | BLOB | - | Текст сценария, управляющего содержимым печатной формы |
| 15 | ParentID | Integer | | ID родительской группы шаблонов |
| 16 | IsFolder | Varchar | 100 | Признак: группа шаблоновнование |

## Особенности

1. Поиск в БД производить по коду
2. При добавлении нового элемента нужно генерировать ID генератором GEN_ID (есть специальная функция в IFrontolMainDb - NextChangeId() )
3. Справочник иеррхический, 1 уровень вложенности.
4. PrintTarget - подкладной документ (2) неиспользуется сейчас.
5. Вид шаблона - реквизит группы
6. DocOrientation - используется только для подкладного документа
7. MinLines и MaxLines - толко для принртера документов
8. Редактировать вне фронтола мы сможем только PrintTarget == 1, 2, 3 - это ScriptData. Для PrintTarget == 4 - FRData. Нужно просто загружать из фронтола, взможно, позже - загружать из файла.
