# 18.89. PrintGroup/Группы печати

| № | Имя поля | Тип | Длина | Назначение |
| ---: | --- | --- | ---: | --- |
| 1 | ID | Integer | | Уникальный идентификатор |
| 2 | Code | Integer | | Код |
| 3 | Name | Varchar | 128 | Наименование |

| 13 | TaxSystem | Integer | | Система налогообложения: • Не используется; • Общая; • Упрощенная Доход; • Упрощенная Доход минус Расход; • Единый  ельскохозяйственный налог;• Патентная система налогообложения. |
